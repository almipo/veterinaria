# config-server

Configuración centralizada nativa desde `src/main/resources/config/`.

- Puerto local: **8888**.
- Ruta de comprobación: `http://localhost:8888/ms-auth/default`.
- Iniciar desde IntelliJ la clase `@SpringBootApplication` correspondiente.

Consultar [`../README.md`](../README.md) y [`../docs/revision-sprints.md`](../docs/revision-sprints.md) para arquitectura, pruebas y pendientes.
